## Notes

- Task 4 (stress scene, 4000 statics / 300 bodies / 200 triggers, `engine_bench`): fixed update 20.4 ms -> 4.7 ms,
  1000 raycasts 83 ms -> 1.3 ms, draw list 9.7 ms -> 0.2 ms; simulation checksum unchanged. Remaining cost is
  mostly the physics world being rebuilt twice per update (world matrices + tree): an incremental update would be
  the next step. Mesh colliders still test every triangle (no per-mesh tree).
- Rendering can be checked headless: `xvfb-run -a vkworld --screenshot out.png` (lavapipe).
- Task 1: the engine is a shared library now (ImGui inside it, WINDOWS_EXPORT_ALL_SYMBOLS on Windows) so modules
  share its registry and ImGui context. Modules are loaded from a temp copy (rebuildable while loaded). Unknown
  behaviour types load as MissingBehaviour placeholders (no more load failures). Windows/macOS module loading
  is untested here (no CI access from this machine).
- Task 2: ctx.loadScene / quit / state() / saveGame / loadGame; Behaviour::state() for runtime state in saves;
  built-ins SceneExit and SaveLoadKeys; scene format 9 (quicksave / quickload actions added to older files).
  The sample game has two levels with the score carried over.
- Task 3: Behaviour::drawUI + GameUI (canvas 1080 high; text, rect, border, bar, image, button; own hit-testing);
  ctx.setPaused / paused; InputMap::pressedThisFrame; HudText / HudBar / PauseMenu built-ins; GameState::format;
  scene format 10 (pause action); module API 3. Images use the texture's descriptor set as the ImTextureID.
- Task 5: GPU skinning (SkinVertex stream at binding 1, joints SSBO at set 0 binding 3, instance params.w = first
  joint); Skin / Animator components (joints and targets by name under the model root); clips in
  MeshLibrary::animations, re-imported from "file#animN"; cross-fades; scene format 11; module API 4. Skinned meshes
  aren't frustum-culled. Animation runs at the fixed 60 Hz (no render interpolation). No editor preview outside Play.
- Task 6: GGX metallic-roughness with hemisphere ambient + analytic env BRDF; derivative-based normal mapping;
  emissive; material descriptor sets (4 maps) cached by texture ids; textures have sRGB + UNORM views (UI uses
  UNORM, which also fixed GameUI images being too dark); HDR R16G16B16A16 target, bloom mip chain (6 levels),
  PBR Neutral tonemap; outline marked with alpha 2. Scene RenderSettings (format 12). Module API 5.
  Not done: point-light / cascaded shadows, image-based lighting, SSAO.
- Task 7: Jolt Physics v5.6.0 vendored (third_party/JoltPhysics, its own Jolt.cmake, every option off), hidden
  behind RigidBodies (pimpl). Scene is the source of truth; changes since the last step are detected (moved
  entities, velocities). Statics turn kinematic when moved. Shape key compares with a tolerance (Euler round trip
  noise used to re-create bodies every step). Penetration slop 2 mm, linear cast threshold 0.1. Shapes shared by
  key. Stress fixed update 7.1 ms (Jolt + two PhysicsWorld builds). Characters still use our own capsule mover;
  Jolt's CharacterVirtual would be the next step. Joints aren't exposed.
- Task 8: app/export (exportGame), File > Export game..., `vkworld <project> --export <dir>`. Verified on Linux:
  the exported folder, moved elsewhere, runs the sample with its module (RUNPATH $ORIGIN). Not done: a single-file
  build (static engine + packed assets), stripping debug info, icons / app bundles.
- Task 9: CI smoke step (lavapipe + Xvfb + validation incl. sync; game, stress editor, exported sample;
  tools/check_screenshot.py); --screenshot runs exit 1 on validation errors / failed screenshots. Locally the
  validation layer (unpacked with apt-get download, VK_ADD_LAYER_PATH) reports nothing, sync validation included.
  renderer.cpp split in four (+ renderer_internal.h), editor_panels.cpp in three (+ editor_ui.h). Format fixtures
  v2..v11 generated by building each historical commit (tests/assets/formats).

### Round 2 notes
- Task 10: Windows needed vulkan-1.dll delay-loaded (the runner has no Vulkan runtime; the engine DLL imported it)
  and a test path fix; four MSVC/Clang warnings fixed. macOS can't run a smoke test: MoltenVK aborts in
  vkCreateInstance on the runners' paravirtual GPU (no argument encoders). All three platforms green.
- Task 11: undo steps are SceneDeltas (scene/scene_diff); operations copy the scene once (diffed at the end of the
  frame), widget edits compare against the frame-start selection / look / bindings. Transform::matrix skips the
  trigonometry for unrotated entities (bit-identical): worldMatrices 1.27 -> 0.15 ms on the stress scene.
- Task 12: physics/physics (Physics) replaces PhysicsWorld + collision.* + RigidBodies: Jolt narrow-phase queries,
  triggers as sensor bodies with enter/exit computed by CollideShape after each step (same-step semantics as
  before), characters as CharacterVirtual (inner body for queries; stairs, stick to floor, ground velocity).
  Stress fixed update 5.9 -> 2.9 ms. The editor draws collider wireframes from the components.
- Task 13: ParticleEmitter component (scene format 13), game/particles (CPU, fixed update, world space, orphaned
  particles live on), renderer billboards from a storage buffer (binding 4) in the HDR pass: alpha (sorted) and
  additive pipelines, premultiplied, depth-tested without writing. Editor preview system. Module API 7.
- Task 14: 4 sun cascades (2048, 160 m, log/linear splits, bounding spheres, texel snapping, per-cascade culling)
  and 4 spot shadow maps (1024) in two depth arrays, one shadow pipeline with a layer push constant; spot lights
  (cone + softness, scene format 14); procedural sky pass (after opaque, at the far plane) and sky-based IBL
  (irradiance + roughness-blurred reflection). Not done: point-light (cube) shadows, a real prefiltered cubemap.
  Module API 8.
- Task 15: MeshRenderer alphaMode / opacity / alphaCutoff (scene format 15, glTF import), cut-outs discard in the
  opaque pass, see-through objects in a transparent pipeline (premultiplied, no depth writes, sorted by centre).
  Built-in Grate texture; demo Glass and Grate. Not done: alpha-tested / tinted shadows, order-independent
  transparency. Module API 9.
- Task 16: core/vfs (packs: files + table + footer, mountable standalone or appended to an executable; every loader
  reads through it: scenes, project, textures, OBJ, glTF via cgltf callbacks, sounds decoded from memory, shaders);
  export layouts Folder / Pack / SingleFile; VKWORLD_STANDALONE_GAMES builds engine_static and <module>_game
  (module registered directly). macOS .app bundle, Linux .desktop entry. Not done: window icons, Windows .exe icon
  resources, compression in packs.
- Task 17: AnimationEvents (clip, time, name) fire Behaviour::onAnimationEvent once per pass (loop wraps
  included); Animator state machines (states with clip / speed / loop, transitions from a state or any on a
  parameter > / < / true / false or on the clip ending, with cross-fades; parameters set by game code). Scene
  format 16, module API 10. Editor: Animator inspector in editor_animation.cpp with clip preview / scrubbing outside
  Play (posed only while building draw items, then restored), event and state machine editing. Game::worldMatrices
  and activeCamera interpolate the last two fixed updates (off while paused; setInterpolation). Not done: blend
  trees / layers / masks, a graph view of the state machine.
- Task 18: FieldVisitor gains int (range), choice (options; saved by name, numbers accepted) and FieldRef string
  references (Entity, Prefab, Scene, Sound, AnimationClip, InputAction), with fallbacks so visitors that only know
  the four basic kinds keep working. The inspector shows DragInt / Combo / text box + picker list + drops
  (outliner entities, asset browser scenes / sounds) + an unknown-name warning. References stay names (spawned
  entities match; files stay compatible); built-ins and the sample use them (Spawner maxAlive is an int, HudText
  align a choice). Module API 11.
- Task 19: game/navigation (NavGrid), not Recast: a multi-level walkable grid baked from static colliders
  (Physics::raycastAll down each column, slope and headroom checks, links within maxClimb, diagonals only between
  open sides, erosion by agentRadius via Dijkstra from edges; columns probed on worker threads), weighted A* with
  reused scratch + straightening along the links. Scene format 17 (scene.navigation), undo covers it. Game bakes
  lazily (GameContext::findPath / navigation / rebuildNavigation); NavAgent built-in; sample Chaser uses paths;
  editor Bake and show + View > Show navigation overlay. Stress scene (600 m, 2.2 M cells): bake 1.35 s on 2
  cores, 0.47 ms per long path. Not done: dynamic obstacles / local avoidance between agents, off-mesh links
  (jumps, ladders), baking in the background, saving the baked grid. Module API 12.
- Task 20: game/scene_loader (SceneLoader: loadScene on a std::async worker into its own libraries seeded with
  the built-ins, then mergeSceneAssets on the main thread: meshes / textures / clips deduplicated by source, ids
  and clip names remapped in entities and prefabs). Game::setAsyncLoading (vkgame, editor play): loadScene freezes
  the game behind a default loading screen (GameUI spinner; showLoadingScreen / loading for custom ones); save
  loads cancel a pending change. Streaming: GameContext::streamIn / streamedIn / streamOut (chunk = a reserved root
  entity id, entities re-id'd and pushed through the spawn queue so behaviours start, prefabs merged by name, nav
  marked stale); StreamingZone built-in. Not done: Game::start's physics body creation is still on the main thread
  (the stress scene's ~55 ms), the first scene of vkgame loads before the window opens, no load progress fraction,
  GPU uploads of new assets still happen in one frame. Module API 13.

### Round 3 notes
- Task 21: SceneLoader::start(path, physics) also makes the Physics world on the worker (Jolt init is call_once);
  finish() remaps its mesh ShapeKeys (Physics::remapMeshes) and swaps it in (Physics::swap); Game::begin(fresh,
  keepPhysics) keeps it. Load progress through a thread-local hook in serialization (assets 0..0.8, physics to 1)
  shown as a bar on the loading screen. vkgame opens the window first and loads its start scene through
  Game::loadScene (screenshot runs wait for it; a failed first load is still fatal, Game::loadError); a scene file
  argument now finds its project (folder above with project.json). Renderer: mesh buffers keep 50 % spare and only
  new ranges are copied (host-visible); textures upload inside the frame's command buffer, 24 MB per frame, staging
  freed after that frame's fence. Stress scene change: 118 ms -> 2.6 ms on the main thread. Not done: the old
  world is still destroyed on the main thread; a real staging ring / transfer queue; mesh buffers device-local.
- Task 22: Entity::tags and Entity::layer (scene format 18), LayerSettings (32 names, symmetric collides matrix;
  undo covers it); Jolt object layer = layer * 2 + moving, ObjectPairs checks the matrix, triggers query with the
  sensor's row, characters use their layer (in their shape key), queries take a layer mask (Physics::raycast /
  raycastAll / overlapSphere, ctx.layerMask). GameContext: findWithTag / findFirstWithTag (spawned included),
  send / sendToTag / broadcast with Behaviour::onMessage (delivered in flushQueues, interleaved with spawns, 8 rounds
  then dropped), after / every / cancel / sequence (Game::runTimers after the behaviours' updates; owner-bound;
  cleared by begin). Editor: tag chips + layer combo, Layers settings with a meet matrix. Fixed a dangling
  json::Value reference pattern in the writer. Module API 14. Not done: timers in save games, layer-filtered
  navigation, a message log in the editor.
- Task 23: Joint component (fixed, ball, hinge, slider, distance, cone = SwingTwist; anchor / axis in the entity's
  space, limits, hinge / slider velocity motors, break force from the constraint's position lambda / dt, collide
  connected via one GroupFilterTable rebuilt when the jointed pairs change) and RigidBody::kinematic; scene format
  19. Constraints are keyed by their settings and both BodyIDs (remade when a body is), the other body is body 1
  (angles and motors are the entity's), removed with either body. The other entity is resolved by name under the
  nearest ancestors first. Write-back of simulated bodies now goes ancestors first against live parent worlds
  (parented chains). game/ragdoll: makeRagdoll (capsules along Y-pointing bones, else spheres; mass by length;
  cone joints 40 deg) and setRagdollLimp / ctx.setRagdoll. Editor: Joint inspector, Kinematic, Skin > Make ragdoll.
  Module API 15. Not done: joint gizmos in the viewport, carrying the animation's velocity into a limp ragdoll,
  six-DOF / gear / pulley constraints.
- Task 24: updateAnimators rebuilt on "sources" (a clip, or two clips of a 1D blend tree mixed by weight and
  sampled at a shared phase over the mixed duration) and per-target pose maps: current source, cross-fade from the
  previous source (fadeFromState: blend trees fade as one), then AnimatorLayers (clip, mask bone subtree, weight,
  speed, loop; nodes the base doesn't move blend from a captured rest pose), then root motion (rootBone x/z travel
  between the old and new phase, wraps included, pinned to its start; Game moves the entity: moveCharacter for
  capsules / spheres). Animator::play() clears the state; playLayer / stopLayer. Scene format 20. Editor: blend
  tree points, layers with mask pickers, root motion bone, and a state machine graph window (circle layout, any-state
  arrows, conditions on hover, live state). Module API 16. Not done: 2D blends, additive layers, events on blend
  trees, editing in the graph.
- Task 25: prepareNavLevel copies the level (static colliders, NavLinks, transforms, only the meshes mesh colliders
  use) and hashes it; NavGrid::bake(NavLevel) runs on a worker (Game::startNavigation when the scene has NavAgents
  or links), or a saved "<scene>.vkw.nav" with the same hash is loaded (binary, via the VFS; editor Bake and
  save). NavLink component (scene format 21): off-mesh edges in A* (cost x length, one or both ways), paths split
  at links and straightened per walk, findPath(..., jumps) marks them. Obstacles: rigid bodies (non-kinematic) and
  "NavObstacle" tags, from Physics::bodyBounds every 15 ticks, block cells (inflated by the agent radius) for A*
  and walkable(). NavAgent: hops links on an arc, personal-space separation from other agents. Module API 17. Not
  done: true local avoidance (RVO), obstacles carving per-frame, links for characters other than NavAgent,
  rebaking only the changed tiles.
- Task 26: point-light shadows (2 nearest casters, 6 x 512 faces at 95 deg in a third shadow array, binding 6;
  the shader picks the face by the major axis; matrix table 8 -> 20, computeShadows assigns every light's layer);
  unused point layers aren't even cleared. Cut-out shadows: shadow.vert passes UV / opacity / mode, a second shadow
  pipeline (PipelineDesc::shadow) with shadow_cutout.frag discards by the albedo alpha (Mask: cutoff; Blend: 0.5),
  casters with holes batched by material set. SSAO: the MSAA depth is stored and sampled (sample 0, depth-only
  view), ssao.glsl (12-sample cosine hemisphere, normals from the nearer neighbours, oriented by the cross order)
  at half size into an R8 image, applied with a 4-tap blur in the composite; RenderSettings aoStrength / aoRadius
  (scene format 22), SceneRenderInfo zNear / zFar, push constants 48 bytes. Module API 18. Deliberately not done:
  a prefiltered environment cubemap (the sky is analytic and smooth: environment() already evaluates it per
  direction with roughness blur; worth it once skies are textures), GPU culling (collectDrawItems on the 4700-entity stress
  scene takes 0.43 ms; the renderer's own culling and batching aren't timed headless).
- Task 27: AudioEngine buses (ma_sound_group per AudioBus: effects, music, ui, ambience) with volumes and timed
  ducking (update(dt) eases levels); effects and ambience feed a custom ma_node reverb (Freeverb: 4 combs + 2
  all-passes per channel, wet / room / damping atomics) into the endpoint; streamed sounds keep the file's bytes
  and decode through ma_decoder on the audio thread; playMusic / stopMusic cross-fade (stop with fade, released in
  update); Doppler from sound and listener velocities (Game measures them per frame). AudioSource bus / stream /
  doppler, ReverbZone component (scene format 23), GameContext playMusic / stopMusic / setBusVolume / duck, built-in
  MusicPlayer; editor inspectors. Module API 19. Not done: a settings menu for volumes, saving bus volumes, HRTF,
  occlusion of sounds behind walls.
- Task 28: multi-selection (Editor::selected_ stays the primary; extraSelected_; Ctrl+click toggles in the viewport
  and outliner, Shift+click ranges in scene order, Ctrl+A roots; outlines for all; the gizmo applies the pivot's
  world delta to the top-level selected; delete / duplicate act on them; undo records the group through
  frameGroup_). Nested prefabs: a prefab's entities may link to other prefabs, Entity::nestedPrefab remembers that
  link in instances (scene files: "nestedPrefab"), makePrefab keeps links, prefabFromTree maps them back, and
  propagatePrefabChange runs syncPrefabInstances on each containing prefab (as a scene of its own) and recurses;
  variants are prefabs whose root is an instance of another (Make variant). Asset thumbnails: addThumbnail
  (box-filtered, <= 96 px, two decodes per frame) shown with their aspect, icons for the other kinds. Panels resize
  by splitters (ImGui windows over the edges). Fixed on the way: Dear ImGui 1.92's Vulkan backend wants
  sampled-image sets (its own layout), so UI images now come from ImGui_ImplVulkan_AddTexture, made per texture on
  first use (validation caught the old combined-sampler sets once thumbnails drew images). Module API 20. Not done:
  real docking (needs Dear ImGui's docking branch), 3D previews for models / prefabs / scenes, saving the panel
  layout, more than one level of nested links inside a single instance, exporting nested prefabs.
- Task 29: core/profiler (PROFILE_SCOPE; frames between Application::beginFrame calls, main thread only; 120-frame
  history; summarize() as a tree keyed by parent paths) with scopes in the game (fixed update parts, audio), the
  renderer (fence wait, instances, recording, acquire, submit, present) and the editor; GPU pass times from a
  timestamp query pool per frame in flight (read after that frame's fence). app/profiler_view: the editor's window
  (frame graph, last-frame bars, averages, GPU passes) and vkgame's F3 overlay. core/log: logfile::open (rotates to
  .1) / write (timestamped, flushed, thread-safe) and logLine (stderr too) for game messages, validation,
  VK_CHECK and fatal errors; game.log / editor.log next to the saves. Editor autosave every 60 s of unsaved edits
  (an edit counter from the undo steps) into the user data folder; Recover autosave when it's newer than the scene
  file; "unsaved" in the status bar. Also: shadow pipelines take an attribute mask (no unused normal input: the
  last validation warning). Not done: GPU scopes inside passes, a capture-to-file / chrome://tracing export,
  crash dumps / stack traces.
- Task 30: game/fonts (Roboto-Medium embedded via cmake/embed_file.cmake; project TTF / OTF loaded through the
  VFS; fonts are added between frames: font() queues, Application::beginFrame calls loadPending before NewFrame;
  per ImGui atlas, so test contexts start clean). Dear ImGui 1.92's dynamic atlas rasterises glyphs on demand: no
  glyph ranges. GameUI::text / textWidth take a font. game/strings (StringTable: strings/<lang>.json flattened to
  dotted keys, English underneath, get with fallback, {@key} translate, languages()). Game::setLanguage,
  GameContext text / format / setLanguage / language, Game::context(); project.json "language"; vkgame
  --language; editor Game > Language. HudText (font field), HudBar and PauseMenu translate; the sample game has
  en / es tables and translated HUD texts. Module API 21. Not done: right-to-left and complex shaping (no
  HarfBuzz), plural rules, a string editor in the editor, fonts for the editor's own UI.
- Task 31: platform::setWindowIcon (X11 _NET_WM_ICON, Win32 CreateIconIndirect + WM_SETICON, macOS Dock image),
  vkgame sets the project icon. Exports: pngSize / makeIco / makeIcns (PNG-in-ICO, PNG-in-ICNS with the type by
  size); Windows writes the icon into the copied executable (UpdateResource, RT_ICON + RT_GROUP_ICON 1) before a
  pack is appended; macOS writes Contents/Resources/icon.icns + CFBundleIconFile. core/compress: an LZ4-block
  codec; packs are VKWPAK02 (a stored size per file; compressed when it saves 5 %), VKWPAK01 still mounts. vkgame
  --check loads pack, project, module and start scene without a window (exit 1 on failure or missing behaviour
  code); CI exports single-file and packed on all three OSes and runs --check from an unrelated folder; standalone
  game executables delay-load vulkan-1.dll on MSVC. The sample game has an icon. Not done: code signing /
  notarisation, Windows icons for vkgame itself, installers.
